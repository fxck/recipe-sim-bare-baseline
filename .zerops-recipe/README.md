# go-api

A small Go HTTP API with a Postgres database. I dropped a `.zerops-recipe/` in
so it can be imported on Zerops, but I didn't write any of the recipe content —
no intro extract, no take-over guide, no integration guide, no knowledge base.

This is the **honest baseline**: with no authored fragments, the recipe page
can't show a clone-and-own guide or an integration walkthrough it would only be
guessing at. It renders the **plain deploy** path — the environment selector for
sizing, and this raw README — and nothing it can't back up with authored content.

Two environments are defined: `0 — Development` and `1 — Production`.
